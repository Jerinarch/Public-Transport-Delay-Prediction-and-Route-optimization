# Internship Report Abstract & Keywords

**Project Title:** An Intelligent Public Transport Delay Prediction and Route Optimization System Using Machine Learning

---

## 1. Direct Abstract (Matching Requested Format)

> In this internship report, we explore the problem of public transport delay prediction and dynamic route optimization using machine learning techniques. The project focuses on developing predictive models capable of forecasting transit delays and generating dynamic commuter detours while minimizing travel delays and schedule disruptions under noisy AVL/GPS sensor telemetry. Key aspects include data preprocessing with KNN imputation, sequential delay propagation modeling, explainable AI (SHAP) for operational transparency, and schedule-aware multi-criteria dynamic routing.
>
> **Keywords:** Public Transport, Delay Prediction, Route Optimization, Machine Learning, Explainable AI (XAI), Smart Mobility

---

## 2. Standard Academic Abstract (Extended Version)

> In this internship report, we address the critical challenge of urban public transport delays and dynamic route optimization using advanced machine learning techniques. The project focuses on developing an intelligent, end-to-end framework capable of accurately predicting transit delay risk probabilities and exact delay durations while minimizing commuter travel time and false-alarm disruptions. Key aspects of the proposed system include robust telemetry preprocessing using KNN imputation for sensor signal loss, sequential delay propagation modeling (SA-SDP), Explainable AI (SHAP) for transparent decision-making, and an Explainable Multi-Criteria Dijkstra Routing (X-MCDR) engine integrated into an interactive dashboard.
>
> **Keywords:** Public Transport, Delay Prediction, Dynamic Route Optimization, Machine Learning, XGBoost, LightGBM, Explainable AI, Data Preprocessing
